Quiet. Nothing blinks or steals focus. A system banner only when nus is in the background, and only for “to you”. Sounds are off until a channel turns them on.
Private. Private windows record nothing. A page’s words never leave the machine except to your own phone page. Each site keeps its own answer in sites.json.
Bounded. A site gets one notice per 10 s. Repeats with the same tag replace the last. The away rows keep 6, the store keeps 30 days.

CEF has no web Notification API
Pages see none, so they fall back to the title. Every option needs nus to supply one: the shim is common.
CEF #2951
No Web Push in CEF
A closed or sleeping page can’t be woken from a server. Only an open page, or a protocol, can tell you.
CEF
Hidden pages slow down
Chromium runs a hidden page’s timers once a minute after 5 min, and nus sleeps pages at 30 min. Listening has to opt out of both.
Chrome 88
Badging API is for installed apps
setAppBadge is rarely called in a tab, so the title count matters more.
MDN, W3C
Gmail and 365 want OAuth
Google’s mail scopes are restricted: verification plus a yearly CASA review. Microsoft has retired basic auth. Their pages, then, not their APIs.
Google, MS
Cheap and push-friendly
JMAP EventSource (Fastmail), IMAP IDLE, GitHub notifications (304 is free), ICS, feeds.
RFC 8620
System banners need an identity
Windows toasts need an AppUserModelID and a Start menu shortcut; macOS needs the signed bundle. nus has only Dock attention today.
WinRT
Recipes rot; stale badges lie
Ferdium’s DOM recipes break when sites ship, and a hibernated service’s old count misleads. Mark stale and broken, always.
