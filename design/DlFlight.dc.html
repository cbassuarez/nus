A · Flight

The file goes where it’s kept. A slip with the file’s name lifts off whatever you clicked and slides to the downloads icon in the sidebar’s foot. When the sidebar is hidden (the default) it slides into the hot edge, and the edge keeps a notch at the icon’s height, filling as it downloads. Your eye follows the file to its place, so you learn where downloads live by watching one go there.

To build. A slip layer drawn in the overlay pass, plus the edge notch. Keep the click point next to gesture_at (only the time is kept today). Reuses Bob, Motion::travel and the drawer’s dot. About a day.
How it reads. You click nus-0.0.3-x64.msi. A small ruled slip with the name leaves the link and slides down-left into the edge, where a red notch fills as it downloads. Rest on the notch to see the name and time left; click it to open the list. Once it’s done the notch turns into a dot, which stays until you look.
Motion. Lift is 80 ms. The slide is Motion::travel(SIDEBAR × 1.6), so 0.16 to 0.44 s depending on the register, on the Glide curve: it starts from rest and lands soft. It never scales or bounces. The catch is the IconMotion::Bob that already exists (“dips and returns, like a download landing”) and has never been used for downloads.
For. Strongest “something happened, and it went there.” Safari has trained people on this for twenty years. It works for a 4 KB file that’s done before the slip lands. The slip can carry a thumbnail when you save an image.
Against. An object crosses the page you’re reading. Bursts need a stack (“3 files”). It flies to a stand-in (the edge notch) more often than to the real icon, because the sidebar is usually hidden.
