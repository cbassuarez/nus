Flow

Ctrl T palette (new) · Ctrl Shift T reopen · Ctrl N new window · F2 rename window · Ctrl 1–9 tabs · Ctrl Shift 1–9 windows.
Click NEW TAB → shell in the default profile; rules colour it. Hold 240ms / right-click / caret → kinds.
Windows are OS windows. Auto-name: git root of the first shell’s cwd → dominant host → “Window n”; window_name(ctx) in rules.luau.
The name shows in the sidebar header, the atlas, the OS title bar, and Alt-Tab.
