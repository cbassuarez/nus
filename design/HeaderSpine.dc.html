Flow. Click a square → that window fronts (OS window, so Alt-Tab agrees). Plus in the spine → new window. Next row → default shell; hold/right-click → kinds. Name → rename in place. The spine is the same list the atlas shows.
Motion. The dashed row fills ink on hover, then on press the dash becomes a rule and the row’s text becomes the tab title (character cross-fade, 120ms) while a new dashed row unfolds below. Switching windows: the square’s tint slides along the spine; the tab list pages sideways. Tooltip rises 4px as it fades in.
Iconography. plus ×2 (spine, next row), pencil on name hover, terminal / globe / columns in the fan-out. No caret anywhere — the spine *is* the list.
Settings. Spine: left / right / hover-only / off (falls back to the dropdown). Next row: dashed / ghost plus / off (band instead). Name: auto / fixed.
