The verb. ⌘D keeps the page in front (or the shell's command, the file, the note) with nothing to fill in: no folder required. It goes in this project when the window is bound to one, else in personal. ⌘D again undoes. Every surface that offers "save" today calls this one verb: SAVE TO FOLDER, SAVE TO READING LIST, PIN THIS TAB, SAVE SHORTCUT.
Finding beats filing. Kept items outrank history in the palette and the address field. A kept copy's text is searchable. History may suggest (visited on 4 days, not kept: keep?), never act.
Notes stay files. A bookmark is where; the reading list is what's left to do, a state on the bookmark; a note is what you think. They meet by links: the notes index already knows every URL a note mentions, so the page asks which notes cite it. "Write about it" opens a note with the page as its first source.
Two homes. Personal items live in the profile and are encrypted like history. A project's live in <project>/.nus/ beside its notes, plain, shared through git only if you say so.
To build. The record grows from library_store (per item, revisions, tombstones, copies, unknown fields kept). One way to tidy an address for duplicates. Migration in place: pins, plain folders, prompt.saved URLs, library entries; library's note: entries become notes. Import keeps the folder tree as collections; export to bookmarks HTML and JSON.
