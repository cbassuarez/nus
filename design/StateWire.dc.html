the window, summed · the top strip counts the wire

1 waits·1 failed·3 running·1 donenus
Words, only when there's news. A row is one line until its tab has something to say; then a second line, the wire, says it, verb first: RUNNING 1:42, WAITS, FAILED, LISTENING, PLAYING, DONE. When it's said and seen, the line goes away. So the sidebar's shape is itself the signal: the tall rows are the ones with news.

The edge at each row's left is a code you can read without colour: solid (waits), hatched (failed), dashes that walk (running), an outline (done, unseen). Only the dashes move.

Stacks take the loudest member's edge and say how many of each ("1 waits · 1 running"). The top strip says the same for the window, so a hidden sidebar still reports.

Cost. Rows change height when news arrives (eased, 160ms, and never under the pointer: a row under the pointer waits until it leaves). The wire's words must be short and reliable, so each one has a source (common ground).
