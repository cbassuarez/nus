Flow. Click NEW TAB or the next row → default shell. Caret, hold, or right-click → kinds (shell profiles as squares, page, split). Window cell → list with rename and new window. Name ellipsises; the square always shows the window’s colour.
Motion. Hover fills the cell ink (60ms). Press: the next row solidifies into the tab (dashed → rule, ghost plus → numeral, 120ms) and a fresh ghost row unfolds under it. Fan-out slides down from under the caret. Window switch: the tab list pages sideways 140ms, the square fill travels.
Iconography. plus, caret-down ×2 (window, kinds), check, pencil (only inside the list), globe, columns, terminal. Shell profiles are 14px squares in the fan-out — no text.
Settings. Window cell: square + name / square only. Next-row button: on / off. Kinds: caret / hold / both. Hover: fill / underline.
