Flow. Click NEW TAB → default shell (rules colour it). Hold 240ms or right-click → kinds. Click the name → windows; double-click or F2 → rename; Enter commits. Ctrl N new window. Auto-name: git root of the first shell → dominant host → “Window 2”; window_name(ctx) in rules.luau overrides.
Motion. Caret fades in on hover (80ms). List unfolds: the rule extends down, rows fade in 20ms apart. Press: band flashes ink→signal→ink over 120ms; the new row grows 0→32px from the list bottom and its numeral fades in last. Rename: the caret blinks on the cursor register; commit cross-fades the name.
Iconography. Phosphor only: plus, caret-down, check (current window), terminal, globe, columns (split), pencil never shown (rename is the caret). Windows are signal squares, same as tabs’ rules colours.
Settings. Dateline: cwd · tabs · ports / off. Band: inverted / outlined. Name size: 24 / 18. Hold fan-out: on / off.
