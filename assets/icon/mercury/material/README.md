# Fluid ribbon Mercury material fields

Six actual bundled font faces share one continuous rounded silver volume. The
silver orbit carries a narrow emitting seam driven by arbitrary Space RGB.
These fields contain compact 256px and genuine 1024px response levels. They use
the same seven-knot scene-linear encoding and display transform
as the regular enamel fields. White metal reflections remain visible as the
signal changes. Blender is required only for regeneration.

Master: nus-promo/out/logo-3d/fluid-ribbon/nus-mercury.blend.
Builder and editable controls: nus-promo/blender/mercury.py and rounded_n.py.
Regenerate using bake_dock.py --kind mercury. Bank hashes and render settings
are in manifest.json. Direct Cycles and native-response comparisons pass across
the six fonts and sampled Space colors. Live application acceptance is separate.

The native build also passes `scripts/check-mercury-material.py`: current
Settings tile selection and claiming, Space-driven Dock readback, saved
selection, reduced motion, and narrow/short presentation bounds. Manifests
retain the baked-master hash when only portable source or notes change.
