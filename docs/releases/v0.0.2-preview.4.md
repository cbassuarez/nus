# nus 0.0.2 preview 4

## Release summary

- Curated complete themes: ten originals with coordinated colors, fonts, spacing, frames, cursors and artwork, including four work themes and OLED-black Carbon. Loading-animation settings remain independent.
- Home shares the command palette’s routing, actions and browser shortcuts, with clear search and website entry, draft handoff and visible keyboard selection.
- PiP ignores silent autoplay previews, keeps its relevant screen corner fixed while resizing, restores playback from the original page notice, and uses swept-arrow controls with clearer hover feedback. Rapid skips preserve playback state.
- Home animation pacing and bounded caches reduce redundant work and allocations; inactive artwork stops requesting animation frames.
- Native Sky adds bounded volumetric clouds, Sun/Moon lighting and optional forecast conditions for an explicitly chosen place.
- Toasts remain visible above browser content. Browser error screens, retry layout and input handling are corrected.
- Windows gives the application DLL a distinct build name to avoid parallel linker intermediate-file collisions. Linux packaging installs the missing X11 keyboard runtime required by browser validation.

## Validation and boundaries

Local validation includes 610 native-app tests, the root workspace tests,
formatting and Clippy, 25 packaging tests, three support-policy tests, and
JavaScript media/rapid-skip checks. Native macOS theme, home-prompt, PiP,
artwork and memory-recovery evidence is recorded under docs/performance and
in the Preview 3 audit. These checks do not substitute for native Windows
and Linux acceptance.

The release workflow builds and tests all three platforms, exercises packaged
browsing and failure recovery, signs Windows artifacts and publishes only a
complete passing matrix. Preview 3 was not published because its Windows
link and Linux runtime checks failed; their fixes are included here.

Weather is opt-in and uses the chosen coordinates; no location is discovered
automatically. Forecast conditions do not represent exact observed cloud
geometry. GPU and allocation measurements are workload-specific, not general
battery-life guarantees. Browser BGRA upload on Windows/Linux retains its
existing bandwidth tradeoff. Loading-animation preferences, accessibility
overrides and functional settings stay independent of theme selection.
