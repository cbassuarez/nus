# nus 0.0.3 preview 1

## Release summary

- Regular and Mercury icons now use the approved Blender forms: pearlescent enamel with a polished black stroke and glass orbit, and a liquid-silver ribbon with a signal-colored light seam. Curved backs replace straight extrusion walls. All six bundled font faces and arbitrary Space colors remain settings-driven, with sharp 1024px exports and compact cached Dock assets.
- Restored tabs no longer play a cascade of page-ready sounds at startup. Initial restoration stays quiet across redirects, split panes and other windows; new tabs, later navigation and reloads keep their normal cues.
- The header puts assistant, note and settings actions within reach, including narrow windows. The assistant uses the current tab's shell; a new note preserves an occupied split and opens separately when needed.
- Settings opens as a window view above the current work. The gear, Escape and the close shortcut return to the same tabs and input; settings search, scrolling, zoom and accessibility follow that view.
- Window choices stay readable and clickable beside a compact sidebar. Theme swatches remain centered in their footer cell, including the fanned hover state.
- Updates shows a quiet status summary with the running version, actual check result or activity, and last-check time. A failed attempt never claims the app is current. Profile, recovery, support and privacy details expand in place and remain searchable; restart review keeps its interruption warning.
- First-open, restored, cascaded and dragged-tab windows fit inside the usable desktop. macOS accounts for the Dock and Windows for the taskbar; valid saved frames keep their position and size. Linux uses monitor bounds, with positioning left to Wayland where required.

## Validation and boundaries

The local candidate passes locked root-workspace tests (259 passed, one explicit
GPU-readback ignore) and native-app
tests (705 passed, four explicitly ignored), release tests (32 passed, one
platform-specific skip), 39 script tests, browser media transport and rapid PiP
checks, root formatting and Clippy. The Mercury
small-size regression measures fractional alpha coverage while retaining its
silver-contrast and transparent-corner checks.

The icon assets were compared with their Blender references and checked through
native Settings, Space-color changes, Dock readback, saved selection and reduced
motion. The native session-sound regression uses delayed localhost pages, a
redirect, a split pane, two windows, new navigation, both reload modes and an
actual relaunch. It observes the native sound dispatcher; it does not record the
physical audio device. This regression is also a macOS packaged-release gate.

Header, compact-sidebar, updater and native window-placement checks use
disposable local profiles. Updater review uses inert fixtures and does not
install an update. These macOS checks do not establish Windows or Linux native
acceptance.

The Release workflow builds and tests macOS arm64, Windows x86-64 and Linux
x86-64, then exercises packaged browser rendering and native failure recovery.
Publication requires every platform job to pass. Windows packages and the
installer require Azure signatures and install/update/uninstall checks. macOS
remains an ad-hoc signed preview while notarization credentials are incomplete.
The published workflow and `release.json` establish the actual package revision,
checksums and signing outcome. Optional package-manager and download-site
integrations require their own repository credentials.
