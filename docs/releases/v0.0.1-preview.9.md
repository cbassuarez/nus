# nus 0.0.1 preview 9

## Release summary

- Optional tools install into separate profile directories, verify their expected files, report start/success/failure, and wake the UI when finished. Removing a tool preserves other tools and externally managed installations.
- Corrected Taplo asset URLs, native gzip/zip extraction, executable permissions, and profile-local npm/Go installation. Missing package managers receive actionable errors. Newly installed language servers become available to existing buffers and prompts.
- Notices outside the editor appear as toasts instead of disappearing into an absent editor status row.
- Failed main-frame navigation keeps the requested destination visible, including redirects; failed subframes do not replace the page address.
- Local pages keep Plot’s dashed boundary without the additional colored loading strip. Loading state follows Chromium’s lifecycle and settles after completion or failure.
- Sidebar hover runs before page-specific pointer handling, clears stale hide timers, and resamples the pointer when focus returns on supported desktops.
- App Icon settings includes selectable artwork cards for the standard faces and earned Mercury. The selection persists; choosing another icon does not remove the Mercury badge.

## Memory pressure

Bounded incomplete terminal sequences, image transfers/decoding/retention,
hyperlinks, shell marks, and custom artwork allocations. Failed surface draws
no longer enqueue scene uploads while waiting for a drawable. Under system
pressure, nus reclaims disposable caches and notifies Chromium without closing
tabs, losing unsaved state, or terminating processes. Native regression checks
exercise repeated browser lifecycles and pressure reclamation.

The reported system-wide spike has not been reproduced or attributed to nus.
These fixes remove concrete growth paths; they are not a guarantee that arbitrary
web pages or external processes cannot exhaust memory. See
[resource budgets](../RESOURCE_BUDGETS.md) for limits and diagnostic details.

## Optional tools

Managed files live under `profile/tools/<tool-id>`. Existing system and legacy
profile tools remain available without offering to delete their shared folders.
Node.js/npm and Go remain prerequisites for their respective language servers.
GitHub Copilot CLI requires its publisher’s installer; nus no longer presents a
version probe as an installation command. Downloads use HTTPS, unpack into a
staging directory, reject unsafe archive paths and symlinks, and become installed
only after the expected executable/script files are present.

## Desktop behavior

App icon choices affect the running macOS Dock/app switcher, Windows window/taskbar
icon, and Linux window/launcher artwork where the desktop supports it. Signed
application resources are never rewritten. macOS Finder and the icon shown before
nus starts retain the installed package’s artwork. Mercury ownership is independent
of the selected icon.

On macOS and Windows, focus recovery samples native client coordinates. X11 uses
its pointer query. Wayland retains event-based tracking because it does not expose
a global pointer query. Native visual and interaction checks are performed on
macOS; the release matrix compiles and tests all three shipped platforms.

## Update note

Save active work before installing. Updates can interrupt running processes;
automatic process resumption remains experimental and is not extensively tested.
Exact package hashes, source revision, and signing status are in `release.json`.
