# App-wide bug-fix pass — 2026-09-23

This pass prioritized security, data integrity, process safety and platform failures, followed by UI defects. It is not a claim that the application is free of bugs. Existing unrelated work was preserved.

## Security and process safety

- Vault records now reject parent traversal and symlinked records/directories before legacy migration reads or replacement writes. Migration also skips linked directory roots. Regression fixtures verify external plaintext stays unchanged.
- Secret redaction now covers quoted JSON authorization headers and structured Authorization/Proxy-Authorization fields.
- Port stop targets the selected process rather than writing Ctrl+C to an arbitrary foreground job in its owner tab. Stop and delayed escalation recheck OS process birth identifiers; unknown/stale identities fail closed. Process metadata refreshes each poll to avoid indefinitely retaining a reused PID. Birth identifiers use macOS process information, Linux procfs and Windows GetProcessTimes.
- Rerunning a remembered command opens a fresh terminal. It cannot type into an unrelated running program or the wrong split.
- A tunnel gets its own tab when the owner already has two panes; failed terminal creation does not falsely mark a tunnel active. Commands wait for the new shell prompt.
- CLI connection checks retain their deadline even when a descendant holds stdout open after the checked process exits.

The path and PID checks are defensive checks, not a replacement for a managed agent sandbox or a claim of immunity to every concurrent filesystem/process race.

## Platform and data correctness

- POSIX sh/Dash/Ksh no longer receive Bash-only --rcfile flags, which could make Linux's default shell exit at startup. Bash retains its integration.
- Fish script paths escape apostrophes and backslashes.
- SSH integration preserves option values (ports, identity files, proxy options), and leaves explicit remote commands and noninteractive sessions intact.
- Assistant tool setup locates the packaged CLI in Windows and Linux bin directories as well as macOS Resources. PowerShell detection is case insensitive; cmd.exe no longer receives POSIX-quoted setup commands.
- Editor/LSP buffer matching preserves filename case; canonical existing paths resolve aliases without merging case-distinct files on Linux or case-sensitive macOS volumes.
- Changing a reading-list source disables fallback to its old legacy article and resets completion. The original article file remains intact.
- Unix file viewers open nonblocking before checking file type, so a named pipe named .md or .txt cannot stall the browser I/O thread waiting for a writer.

## UI corrections

- Remembered ports remain visible in all grouping modes and support the same title/filter logic. Process-group counts reflect visible matches.
- Connection and Docker details no longer describe themselves as TCP listeners.
- Renaming a Station row shows edits immediately instead of continually restarting the flap cascade.
- Narrow import rollers cannot compute a negative font size.
