# The shot list for nus.dev.
#
# scripts/shots.ps1 hands this to the app as NUS_SHOT, once per face. The app
# runs it on its own event loop and photographs itself from its own texture —
# nothing here is OS input. The verbs are documented in
# spikes/composite/src/shot.rs; {repo} is filled in by the driver.
#
# Each `shot NAME` writes NAME-<face>.png. The optional numbers are a crop as
# fractions of the window: x y w h. The window is 1280×800 logical.

wait 3000
shell cd {repo}
wait 800

# The shell beside a page — the site itself on localhost, hazard tape and all.
url http://localhost:8000/
wait 4500
shot window

# The browser pane's content only, tape included, on a page that is plainly a
# page: it goes inside the hero's HTML chrome, so no chrome in the crop.
url http://localhost:8000/docs/architecture/
wait 3500
shot hero-page 0.594 0.088 0.406 0.862
url http://localhost:8000/
wait 3500
